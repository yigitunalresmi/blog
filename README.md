## 🧭 Labyra Ekosistemi

| Ürün | Ne yapar? | |
|:-----|:----------|:--|
| **Labyra ERP** | KOBİ'ler için Türkiye'ye özel ERP — satış, fatura, stok, çek-senet, döviz; yapay zekâ destekli hata tanısıyla. | [2 dakikada dene →](https://demo.labyra.co) |
| **Labyra Label** | Barkod, etiket ve ürün kartı yönetimi, tamamen web'de. CSV yükle, toplu yazdır. | [label.labyra.co](https://label.labyra.co) |
